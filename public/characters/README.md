# Character GLB Assets

Place your low-poly animated character files here:

- `character-1.glb` (default)
- `character-2.glb`
- `character-3.glb`

## Required animations

Idle, Walk, Run, Jump, Jump_Idle, Jump_Land, Wave, Yes, No, Punch, Duck, HitReact, Death, Idle_Gun, Run_Gun, Walk_Gun, Idle_Shoot, Run_Shoot

## Loading URL

Characters are served at: `/api/character/character-1.glb`

Or via rewrite: `/api/character-1.glb`
